GET /contrevenants

Retourne la liste des contraventions entre deux dates.

Paramètres

  • du : date de début (format ISO 8601, ex: 2022-05-08)
  • au : date de fin (format ISO 8601, ex: 2024-05-15)

Exemple de requête

GET /contrevenants?du=2022-05-08&au=2024-05-15

Exemple de réponse

[
  {
    "id_poursuite": 1,
    "etablissement": "MARCHE KIM HOUR",
    "date": "20220101",
    "montant": 4000
  }
]

Erreurs

  • 400 : paramètre du ou au absent, date qui n'est pas au format ISO 8601, ou du postérieure à au.

GET /contrevenants/etablissements

Retourne la liste des établissements triée par nombre d'infractions décroissant.

Exemple de requête

GET /contrevenants/etablissements

Exemple de réponse

[
  {
    "etablissement": "MARCHE KIM HOUR",
    "nombre_infractions": 15
  }
]

POST /inspections

Crée une demande d'inspection pour un établissement.

Corps de la requête (JSON)

{
  "etablissement": "MARCHE KIM HOUR",
  "adresse": "123 Rue Test",
  "ville": "Montréal",
  "date_visite": "2026-04-06",
  "nom_client": "Tremblay",
  "prenom_client": "Marie",
  "description": "Présence de rongeurs dans la cuisine"
}

Exemple de réponse

{
  "message": "Demande d'inspection créée !"
}

DELETE /inspections/<id>

Supprime une demande d'inspection par son identifiant.

Exemple de requête

DELETE /inspections/1

Exemple de réponse

{
  "message": "Inspection supprimée !"
}

POST /utilisateurs

Crée un profil utilisateur.

Corps de la requête (JSON)

{
  "nom_complet": "Marie Tremblay",
  "courriel": "marie@example.com",
  "mot_de_passe": "secret123",
  "etablissements_surveilles": ["MARCHE KIM HOUR", "TIM HORTONS"]
}

Exemple de réponse

{
  "message": "Utilisateur créé !"
}

Erreurs

  • 400 : champ manquant, courriel invalide ou mot de passe de moins de 8 caractères.
  • 409 : courriel déjà utilisé.
